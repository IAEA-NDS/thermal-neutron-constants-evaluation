# References

Audit-trail companion to the evaluation work in this repository. Each
subdirectory paraphrases an external input (email round, paper excerpt, etc.)
that drove a code or data change. Verbatim technical instructions and tables
are preserved inline in quote blocks; surrounding discussion is paraphrased.

The original `.msg` files are kept on the user's local mail/standards-emails
archive and are *not* committed here.
